Direction B

Roll Call

Leads with the names

The boldest of the three. Deep green field, and the six group names set enormous in a high contrast serif, stacked as a type wall. Tap a name and it opens in place with what the group does, who it is for, and an add button. Type is the whole interface. The signup at the bottom flips to light so the form stays easy.

Direction C

The Wayfinder

Leads with where to go

Built with the Banger method: three theses, one composite. The thesis here is Chicago civic signage meets the Senn building. Groups become color coded destinations in arch topped panels drawn from the school's window heads. The page points rather than explains, which is also the most forgiving format for families reading in a second language.

Agreed structure

The information architecture, flat

One page per group. Everything about that group lives on that page as sections, reached by a sticky anchor bar. No third level anywhere on the site.

How it actually works

Five flows

These hold in either direction. They are what the site has to make easy.

1. A new parent joins

Lands on homepage→ Picks one or more groups→ One form, lists prechecked→ Name, student, grade, language→ Confirmation naming their lists + next meeting

2. A returning parent checks what's happening

Homepage or group page→ Filters to their group→ Opens an event→ Add to calendar or RSVP

3. A group officer posts news, an event, or minutes

Opens the shared Google Sheet→ Adds a row on their tab→ Live on the site in about a minute

No code, no deploy, no waiting on one person. Minutes are a row with a Google Doc link, which matches the one-doc-per-year habit already in place.

4. Anyone submits an event

Submit form→ Title, date, image, RSVP link→ Lands as pending→ Admin approves in the Sheet→ Shows on the calendar and the group page

Moderation is one cell. RSVP is an outbound link to whatever the organizer already uses, so there is no attendee database to maintain.

5. A parent contacts a group

Contact form on the group page→ Routes to that group's secretary→ Copy to the shared inbox

The copy matters. When a volunteer rotates off, nothing disappears with them.

The part that decides whether this survives

Who updates it

Today every word on sennparents.com is hand-coded. That works for one group. With six, it makes one person the bottleneck for everyone, and the site goes stale by November.

So the content moves to one shared Google Sheet with a tab per content type: Events, Announcements, Minutes, Efforts, Groups. Each group's secretary edits their own rows. The site reads the Sheet and renders. No new logins, no new tool to learn, no cost, and it extends the Apps Script already running the current signup form.

A seventh group later is a row in the Groups tab, not a code change.
